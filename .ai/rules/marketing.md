# Marketing Rules

**Globs:** `resources/js/pages/welcome*`, `resources/js/pages/marketplace/**`, `resources/js/pages/pricing*`, `resources/js/pages/checkout/**`, `resources/js/pages/onboarding/**`, `resources/js/pages/auth/**`, `resources/js/components/marketing/**`

## Before editing

1. Load the Corey Haines skill that matches the job:
    - `copywriting` for new copy.
    - `copy-editing` for existing copy.
    - `cro` for conversion work on a page or flow.
    - `pricing` for plans, credits, or price framing.
    - `paywalls` for in-product upgrade moments.
    - `signup` / `onboarding` for activation flows.
    - `analytics` / `ab-testing` when the change is measured.
    - `product-marketing` when positioning or audience is unclear.
2. If the surface is also UI, load `impeccable` first; the UI workflow runs before the copy workflow.
3. State the audience, the action being asked for, and the objection being answered before rewriting copy.

## Standards

- Copy passes the Corey Haines skills' anti-slop checks: no "it's not X, it's Y" reveals, no "no X, no Y, no Z" lists, no trailing comma clauses, no fake urgency.
- Claims are supportable. If evidence is missing, name it in the report instead of inventing a number, testimonial, or metric.
- One primary call to action per surface. Secondary actions are visually subordinate.
- Pricing and credit copy states what is charged and what is not. No implied escrow, payouts, or refunds.
- Analytics events exist for the funnel step being optimized, or the report says they do not.

## Evidence

Name the skill used and the recommendations applied. List the headline/CTA before and after. Name any recommendation rejected and why. If the change is conversion-related, state the metric and how it will be measured.
